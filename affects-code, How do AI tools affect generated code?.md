
## AI Tools

Coding agents present a different paradigm compared to AI-assisted IDE's (Agarwal).

## Maintainability 

Really important because it is 3-4x the initial cost of developing the app (Modern Software Engineering).

Using AI produced similar levels of code-quality issues compared to devs without AI (Borg et al.).

## Development Velocity

The effect of AI on short-term development is generally positive (Borg et al., He et al., Paradis et al.). 

On the long term, Cursor offers a generous, initial speed-up that diminishes after a few months, whilst code complexity increases (He et al.). This can be *partly* explained through a self-enforcing cycle, where using Cursor introduces code quality issues (technical debt) that pushes devs to use cursor to fix them, possibly creating more code quality issues (He et al.).

## Downstream Tasks

Using AI sped up initial dev velocity, but the speed up slowed down a lot when it came to releases (Demirer et al.). 

## Attitudes

People enjoy using GenAI (Butler et al.). However, using AI can introduce technical debt and help fuel a cycle of novelty, frustration and abandonment (He et al.).

The speed-up felt from using AI may exceed the actual speed-up in development speed (METR).
