random control trial with 96 google engineers, with the random treatment being the ability to use AI tools consisting of: code completions, smart paste (fitting pasted code to existing codebase) and NL to code. focus on enterprise context (google)

they created a custom task for them that aimed to mirror what they did at google

results: they found a speed up of around 21% to 26%. after controlling for confounding variables, but it was not statistically significant. they estimate it around 21%, that's the headlne figure
- biggest impacts on time spent on task were average time spent programming each day and engineering level
- suggest that folks who spend more time programming per day may benefit more from ai
- engineers with higher seniority seemed to benefit more from using Ai

suggests looking at code quality to see how it is impacted

ok, it was a study with a lot of potential but really didnt provide a lot of interesting insights.

they measured speed using a custom made task. first, the task is custom, and it may not reveal the full complexity of their day-to-day tasks. second, they're measuring at the task level, not how much does AI impact software development as a whole. the MIT sloan study seemed to suggest a bottleneck effect down the line. 

also the speedup they provide is an estimation, esp since controlling for confounding variables showed results that were statistically insignificant 

cool but the study is a bit of a bummer. next is focusing in on code quality, and maybe number of bugs
