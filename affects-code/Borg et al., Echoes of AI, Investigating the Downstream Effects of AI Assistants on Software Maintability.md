#holistic #maintainability #experiment

conducted a 2 phase experiment:
- 150 participants were asked to add a feature to a Java web-app with AI
- RCT to evolve the app without ai

in phase 2, evolving the app written by ai did not present any significant differences compared to the app not written by ai. it took the same time (completion time + productivity), came with the same code quality (Codescene + tests). habitual ai users showed slightly better code quality

in phase 1, ai reduced task completion time by an average of 30.7%, with habitual AI users at 55.9%.

study completed in late 2024

folks using ai in phase 1 added 3x more code compared to the folks who didn't 

points:
- its ok to use ai when it comes to maintaibility
- suggests that companies keep a list of what should still be under human control
